Support

Report a technical problem, inaccurate citation, or question about Maximos.

Open a GitHub support issue. A GitHub account is needed to create an issue. The project maintainer is Eric Bryant.

What to include

  • A brief description of the problem and steps to reproduce it.
  • The work and chapter or passage involved in a citation error.
  • A screenshot with identifying and sensitive information removed, if useful.

GitHub Issues are public. Do not post private counseling conversations, names of other people, health details, passwords, or other sensitive information. Use an anonymous sample to demonstrate the problem.

Privacy requests

You can use an issue to request a private follow-up channel without posting the sensitive details themselves. For ChatGPT account data or conversation deletion, use OpenAI’s privacy controls and support.

Pastoral and urgent needs

Technical support is not pastoral or emergency support. Speak with your priest for personal spiritual guidance and qualified professionals for health needs. If you are in immediate danger, contact local emergency services.
