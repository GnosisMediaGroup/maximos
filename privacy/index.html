Privacy Policy

Effective October 4, 2026. Publisher: Eric Bryant.

Scope

This policy covers the Maximos ChatGPT plugin, its source retrieval service, and this project website. It does not cover the separate Android app. OpenAI, GitHub, and the hosting provider handle data under their own policies.

Data used to retrieve sources

When ChatGPT uses Maximos’s retrieval tools, the service receives the search query and optional source filter and result limit, or the identifier of a passage to retrieve. Search queries can contain information from your conversation. Avoid including names, identifying details, or sensitive personal information in source searches.

The retrieval service uses these inputs to search the corpus and return relevant passages. The server application does not create user accounts or intentionally save counseling conversations or tool queries to a user database. It does not call a separate language-model provider; ChatGPT produces the response.

Hosting and logs

The retrieval service runs on Google Cloud Run. Hosting infrastructure may process technical request information and operational logs. This website is hosted by GitHub Pages. Provider retention settings and applicable provider policies govern infrastructure records; this policy does not promise that all infrastructure records are absent or immediately deleted.

Advertising and sharing

Maximos does not use advertising trackers, sell user data, or intentionally store counseling conversations. Tool inputs are processed by the hosting provider to operate the retrieval service. OpenAI processes your ChatGPT conversation under its own policies. GitHub processes website visits and support activity under its own policies.

Support information

GitHub support issues are public and may remain available until edited, deleted, or otherwise handled through GitHub’s controls. Do not submit confidential conversations or health information. Information you choose to post is used to respond to and investigate the reported issue.

Your choices

You can stop using or disconnect the plugin in ChatGPT. Use ChatGPT’s controls for conversation deletion and data settings. Use GitHub’s controls for content posted there. For questions about Maximos data practices, visit the support page; do not include sensitive information in a public issue.

Changes

This page will be updated if Maximos’s data practices change. The effective date above identifies the current policy.
